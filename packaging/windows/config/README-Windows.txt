ClickUp 本地版 · Windows 安装版
================================

安装目录
--------
程序文件：%LOCALAPPDATA%\Programs\ClickUpLocal
数据目录：%LOCALAPPDATA%\ClickUpLocal\data
日志目录：%LOCALAPPDATA%\ClickUpLocal\logs

使用方式
--------
1. 双击桌面「ClickUp 本地版」，或在开始菜单打开「ClickUp 本地版」。
   程序会在后台启动服务并自动打开浏览器：
   http://127.0.0.1:23090

2. 登录页可以使用演示账号：
   邮箱：demo@clickup.local
   密码：demo1234
   也可以点击「立即注册」创建自己的账号。

两种运行模式
------------
- 后台服务模式（默认）
  安装时勾选「登录 Windows 时自动后台运行」后，登录系统会自动在后台启动。
  也可以从开始菜单运行「启动后台服务」。
  数据与日志都写入上面的目录，不依赖命令行窗口。

- 调试控制台模式
  开始菜单 → 「调试控制台」会打开一个控制台窗口并直接显示 Node.js 日志，
  适合排查端口占用、启动失败等问题。关闭窗口即停止服务。

常用操作
--------
- 查看运行日志：开始菜单 → 「查看运行日志」
- 停止后台服务：开始菜单 → 「停止后台服务」
- 数据目录：开始菜单 → 「数据目录」
- 卸载：Windows 设置 → 应用 → ClickUp 本地版，
  或开始菜单 → 「卸载 ClickUp 本地版」

排查建议
--------
- 如果浏览器打不开，先运行「查看运行日志」，重点查看 server.err.log。
- 如果提示端口 23090 被占用，请先运行「停止后台服务」，
  或关闭占用 23090 端口的其他程序。
- 卸载默认不会删除数据。需要彻底清理时，删除：
  %LOCALAPPDATA%\ClickUpLocal
- 安装包未使用商业代码签名证书，Windows SmartScreen 可能显示
  “未知发布者”。请确认安装包来源可信后再运行。

数据迁移
--------
如果你之前使用源码/命令行版本，数据位于项目目录的 data 文件夹。
可以停止两个服务后，将 clickup.db（以及 uploads 文件夹）复制到：
%LOCALAPPDATA%\ClickUpLocal\data
即可在安装版中继续使用原有数据。
